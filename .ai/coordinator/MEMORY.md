## 项目是什么

- Windows 桌面工具（Electron + React + node:sqlite）：在内置浏览器登录抖音 / 快手 / 小红书，按关键词、话题、作者主页批量抓公开视频元数据，下载视频与封面，FFmpeg 统一成 1080×1920，按设置归档并可导出 CSV。
- **2026-09-29 起用途改变**：本工具现在是**个人学习用途、源码公开（源码可用，不叫「开源」）**，不再面向团队分发。原来为「团队交付」定的规矩（不覆盖分发出去的 EXE、写面向非技术用户的使用说明等）不再是约束；判断许可证、风险时按「个人、非商业、学习」来算。
- 用户的抓取量时大时小。
- 2026-10-07 用户定：许可证改为 **PolyForm Noncommercial 1.0.0**——非商业用途免费，商用（含公司内部业务使用）找作者买商业授权（以后用户会另做一个授权网站）。仓库照样公开，对外叫「源码可用」，不叫开源。之前的版本是 MIT + Commons Clause。
- 项目详细背景、架构、红线清单原在 `docs/视频爬取交接文档.md`（2026-10-06 随内部文档移出仓库，Git 历史里还能找到；§10 红线仍然适用，第 12 条「不覆盖稳定 EXE」除外，那条是为团队分发定的）。

## 长期有效的决定

- 抓取方式默认是「页面自己请求、程序旁听响应 / 读页面注水状态」，不生成签名。
- **2026-09-29 决定：小红书建任务时可选三种抓取模式**（用户要求三个都做）：①**稳妥**（默认）= 在窗口里逐条打开详情页、读注水状态，目标每条约 3 秒；②**快速** = 用登录态在后台直接取详情页 HTML、解析注水状态（借鉴 XHS-Downloader 的思路，自己实现）；③**接口（实验）** = 在已登录的页面里借页面自带的签名函数直接调详情 / 搜索接口（借鉴 MediaCrawler 的思路，自己实现，不搬它的代码）。②③放开了「不代发请求」这条规矩；③最容易因为平台改版失效，账号风控风险也最高，界面上要标「实验」并提示风险。三种模式都保留：遇到验证码就暂停、不绕过，量大时靠间隔、分批控制风控。
- **2026-09-30 路线（用户定）：B 站暂缓，先把抖音、快手、小红书做扎实。** 依据 Codex 的《四平台开源轮子调研》（2026-09-30，在总控工作区，总控抽查过许可证和结构）。可直接借代码：`ljb1020/video-batch-download`（MIT，被动监听思路和我们一致，但只有 57 星，要自己测稳）、`HFrost0/bilix`（Apache-2.0，Range 分片下载，两年没更新）、`xpzouying/xiaohongshu-mcp`（Apache-2.0）。MediaCrawler、JoeanAmier 系列（TikTok/KS/XHS-Downloader）用户要求**学习它们的优点思路**来改进，但不复制代码。借用 MIT/Apache 代码时要在 NOTICE 和许可材料里登记。调研报告「明确不做」里「不在后台主动请求」一条与用户放开的快速模式冲突，以用户决定为准。
- **先抓真机接口再写解析器，不照公开资料写**（快手 GraphQL 的教训：网页端实际是 `/rest/v/search/feed`、`/rest/v/profile/feed`）。
- 快手不返回评论数，`comments` 保持 `null`，不映射成 0。
- 小红书：用户要求**必须能下载视频文件**，所以走两段式（列表收候选 → 逐条导航详情页 → 旁听详情响应取播放地址）。
- 小红书 `xsec_token` 是短期令牌：只在任务内存里用，不落库、不进日志；库里作品链接不带 token。
- 小红书网页「视频」筛选：09-08 曾否决；09-28 Codex 按真机调研改为用 CDP 真实 hover 点筛选面板，失败则回退，解析层仍兜底丢图文。
- 许可证结论（2026-09-29 核对原文）：MediaCrawler（非商业学习许可证）允许个人学习时使用，但**没有授予公开发布的权利**，所以代码不能搬进这个公开仓库，只借鉴思路；XHS-Downloader（GPL-3.0）和本项目的非商业许可冲突，同样只借鉴思路；`xpzouying/xiaohongshu-mcp`（Apache-2.0）可以参考，它也是逐条打开详情页。
- 不绕过验证码，不做账号池、代理池、高并发；验证弹窗一律暂停等人工处理。

## 已验证的工程事实

- `npm ci` 2026-10-06 起能用（PR #30 补了锁文件）。2026-10-07 升到 Electron 44 后，Electron 本体靠 `package.json` 的 postinstall `install-electron --no` 下载。
- 跑测试需真实 Electron 二进制（`ELECTRON_SKIP_BINARY_DOWNLOAD` 会让 5 个测试文件加载失败）。
- 打包时 ffmpeg 从 `vendor/ffmpeg/bin`（不进 git）取，或者设 `FFMPEG_BIN_DIR` 让脚本自动复制（PR #30）。
- Electron 44：页面跳转后，之前发出的 `executeJavaScript` 永远不返回；页面脚本调用都要包超时（PR #49）。
- 验证弹窗检测（`src/main/browser.ts` `buildVerifyScript`）会扫全页可见文字并匹配 `[class*="dialog"]`；在小红书详情页上可能被正文/评论里的「验证码」「verify」等字样误触发暂停——待真机确认（见 pr1 审查）。
