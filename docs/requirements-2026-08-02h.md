# 需求文档：第八轮验收修复（筛选选择器加固/批量暂停）

**日期**: 2026-08-02
**状态**: 待开发（无歧义，无需澄清）
**上一轮**: 第七轮交付，用户反馈 1（时长列）3（定位）绿灯；筛选续爬诊断日志定位根因

## 1. 背景与根因

用户实跑手动测试筛选，日志明确：
```
CDP attach 成功 → 筛选按钮未找到（selector=span.bR4uhU1W）→ 失败
```
**根因**：CDP 真实鼠标链路全部正常，唯一失败点是**筛选按钮的哈希类名已过期**（抖音每次发版哈希类变化）。面板 `div.IMWRHJOg` 同理存在过期风险。

## 2. 核心诉求（2 条）

### ① 筛选选择器加固（不再依赖哈希类名）

- **筛选按钮**：多策略——① 已知哈希类 `span.bR4uhU1W` → ② **文字查找**：DOM 里 `textContent.trim() === '筛选'` 的元素（按钮文本就是"筛选"，哈希无关，稳定）。
- **面板**：① 已知哈希类 `div.IMWRHJOg` → ② 文字查找：含「排序依据」或「视频时长」文本的容器。
- **选项**：优先 `span[data-index1="g"][data-index2="o"]`（语义属性，非哈希，大概率稳定）；找不到时在面板内按文字匹配选项名（如「1分钟以下」「还未看过」）。
- 实现位置：`douyinAdapter.FILTER_SELECTORS` 改为**多候选数组**（每项 {type:'class'|'text', ...}）或提供 resolve 函数；`browser.ts` 的 center/轮询逻辑按候选依次尝试。
- **验收**：手动测试筛选 → 日志显示按钮找到/面板出现/选项点中；真机筛选续爬生效。

### ② 视频表格批量暂停/继续

- TaskList 展开的视频表格工具栏（与「下载选中/取消选中/重试选中」并列）加：
  - **「暂停选中(N)」**：对 selected 中 status ∈ {pending, downloading} 的项调 `video:pause`。
  - **「继续选中(N)」**：对 selected 中 status === 'paused' 的项调 `video:resume`。
  - 计数 N 按各自状态集过滤（沿用现有批量按钮模式：完整 selected 按状态过滤、空则禁用）。
- **验收**：勾选多条 → 批量暂停（在途/排队全停）→ 批量继续恢复；跨页选择语义保持。
