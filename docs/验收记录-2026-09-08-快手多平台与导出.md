- **D** UI / IPC / 下载跟随当前平台：作者输入提示、任务列表中文名、昵称站点后缀、

### 七、本轮修掉的缺陷

1. **幽灵任务**：删掉正在跑的任务只删两行数据，调度器继续滚页面、继续重搜三轮，
   界面上完全看不见。现在删除会停调度器、摘队列、取消在途下载。
2. **队列卡死**（上一条修复引入的回归）：`dequeueAndRun` 只在 `task:done` 时放行，
   而删除走 `pause()` 不发事件 → 排队任务永远没人叫醒。删除末尾显式踢队列。
3. **`ERR_ABORTED` 被当成加载失败**：Chromium 在导航被取代或服务端重定向时以 -3
   拒绝 `loadURL`，而页面通常已正常打开。影响每个任务的页面加载，先前三次抖音
   `network` 失败很可能就是它。
4. **失败原因黑洞**：`run()` 外层是不带参数的兜底 catch，任何异常一律记成
   `network`。现在写入可读原因，页面加载超时单列为 `page_timeout`。
5. **未处理的 Promise 拒绝**：启动落地页失败会触发 `UnhandledPromiseRejection`，
   Node 22 默认因此终止进程。
6. **话题剥不干净**：原规则要求 `#` 前是空格，而中文标题「句号紧跟话题」极常见，
   真机上 `…点名。#搞笑` 漏网。
7. **爬主页写死 200 条 + 自动下载**，不问用户。
8. **删任务不取消在途下载**，留下孤儿文件。
