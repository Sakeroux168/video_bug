## 已实现

1. 关键词与话题搜索会先通过真实鼠标 hover 打开筛选面板，按“组标题 + 选项文字”选择“笔记类型=视频”；近7天同时选择“发布时间=一周内”。面板不可用时会回退到解析与详情精确筛选。
2. 搜索响应只收视频笔记存根，按笔记 ID 去重，跳过已入库视频；即使网页筛选失效，图文也不会入库或计数。
3. 作者主页任务从 `.note-item[data-note-id]` 卡片收集候选，只认带 `.play-icon` 的视频卡片；从卡片链接读取带 `xsec_source=pc_user` 的详情入口，随页面滚动继续收集。作者接口响应本身不含详情令牌，因此不从接口猜令牌。
4. 收够候选数量，或接口 `has_more=false` / 页面到底后，逐条导航到详情页。开启时间或时长筛选时会最多超采三倍候选（总上限 1000）再精确过滤。
5. 用户于本轮提供的真实搜索笔记链接，已确认形态为 `/explore/<id>?xsec_token=<token>&xsec_source=pc_search`；本机作者页卡片已确认 `/user/profile/<uid>/<note_id>?xsec_token=<token>&xsec_source=pc_user`。实际令牌不写入代码、测试、日志或文档。
6. 详情接收器在导航前安装，只接收当前等待 ID 的响应；用户手点的无关笔记及迟到响应不能入库。
7. 完整视频复用既有的时间、时长筛选、AI 筛选、入库、自动下载或手动收集链路。主线的指定下载目录与后续视频处理行为保留。
8. 单条详情等待默认 30 秒，覆盖页面加载与响应等待；超时、加载失败、解析失败写脱敏诊断并跳过。
9. 详情等待可被暂停/取消立即唤醒，同时停止在途页面加载；每条之间遵守滚动间隔。验证弹窗暂停等待人工处理。
10. 继续任务重新打开列表、获取新令牌，并跳过数据库已有作品。任务结束/暂停时清除内存存根。
11. 小红书开放关键词、话题和作者任务，表单、作者列表“爬主页”及后台创建入口使用同一能力声明。

详情不可用或筛选不通过时，实际入库仍可能少于目标，界面会提示实际数量；候选超采有上限，不做无限补抓。

## 待真机验收

本轮验证使用本地夹具和模拟浏览器，没有用登录账号执行真实抓取，不等同于平台烟测通过。

1. 在内置浏览器登录小红书，关键词设置目标 3 条、自动下载，确认筛选面板自动选中“视频”，并观察逐条详情导航。
2. 确认数据库条目与下载文件一一对应，永久作品链接无短期令牌。
3. 抓取中暂停、继续、取消各一次，验证窗口导航及时停止，继续后无重复入库。
4. 用 `ffprobe` 查看下载视频实际编码，验证 EF4/EF5 对应媒体能正常播放；如启用统一分辨率，再验证 FFmpeg 处理。
5. 用一个图文与视频混合的作者主页抓 3 条，确认只处理带播放标识的卡片，且滚动后能继续收集。长期暂停后下载地址过期的重新取址，仍需要真机验证。
