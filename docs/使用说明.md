# 视频爬取工具 —— 使用说明

批量抓取抖音、快手、小红书上的视频信息并下载原视频的桌面工具（Windows）。
软件里左侧「使用说明」页的内容和这里一致。

> 仅供个人学习研究使用，请遵守各平台的用户协议，尊重原作者版权。详见 [README](../README.md) 的免责声明。

## 一、拿到程序

- 下载打包好的 `video-scraper-<版本>-portable.exe`（免安装，双击就能用，自带 ffmpeg），或者按 README 自己打包。
- 放到一个固定文件夹里（别放桌面或临时目录）。

第一次打开时 Windows 可能弹出蓝色窗口「Windows 已保护你的电脑」——程序没有买代码签名证书，所以会这样。
点 **「更多信息」→「仍要运行」** 即可，之后不再拦。第一次启动要解压，等十几秒是正常的。

## 二、开始用之前，先做两件事

### 1. 设下载目录

进 **设置** 页，把「下载目录」改成你自己的路径，比如 `D:\抓取视频`，然后点「保存设置」。
视频很占地方，选一个空间大的盘。

### 2. 扫码登录平台账号

进 **内置浏览器** 页，打开要用的平台窗口（抖音 / 快手 / 小红书），按正常方式扫码登录你自己的账号。
登录状态会记住，各平台互不影响。任务页的状态灯会显示「已登录 / 未登录 / 未确认」，没登录时旁边有「去登录」按钮。

- **快手的搜索必须登录**，不登录看不到搜索结果。
- 开着代理软件时，如果某个平台页面一直打不开（任务提示「页面 30 秒没打开」），把这个平台的网站设成直连再试。

## 三、怎么抓

在 **任务** 页的「筛选条件」里：

1. 选平台，选「关键词 / 作者 / 话题」，填内容
2. 填目标数量——默认 20，建议先试一次，跑通了再加大
3. 点 **「开始抓取」**（或者在输入框里直接按回车）

程序会自己滚动页面加载更多，不用手动操作；抓到的视频默认自动下载到下载目录。
选「手动挑选」的话只收集不下载，之后在任务里勾选想要的再下载。

- **小红书**有「稳妥 / 快速」两种取详情的方式：稳妥是一条条打开笔记，慢但更像真人；快速更快，但更像程序访问。
- **作者主页**可以按日期段抓（时间选「自定义」），也可以在「作者收藏」页点「爬主页」，爬过的博主默认「只抓新视频」（追更）。
- 下载中的视频会显示百分比和速度；任务行展开后能看到每条视频的分辨率、大小、点赞、评论。

## 四、把已有的作者名单导进来

进 **作者收藏** 页，点 **「导入作者」**：

- **直接粘贴**：一行一个，「作者名 + 空格 + 完整主页链接」，逗号、Tab 分隔也行。
- **选 CSV 文件**：表里只要有「作者名」和「主页链接」两列就行，其他列会自动忽略。Excel 文件请先「另存为 CSV」。

导进来的作者显示「待校验」：第一次爬主页时会核对名字和链接是不是同一个人，对不上就不爬，并写明原因。
手机分享出来的 `v.douyin.com/xxx` 这类短链接认不了，要用完整主页链接。

## 五、会遇到的情况

| 现象 | 说明 | 怎么办 |
|---|---|---|
| 任务状态「没登录」 | 平台要求先登录 | 点任务下面的「打开 xx 窗口」，登录后回到任务页点「继续」 |
| 任务状态「需要验证」 | 平台弹了验证码 | 在平台窗口里手动完成验证，然后点「继续」 |
| 任务状态「没有新结果」 | 页面不出新内容了 | 先确认是不是没登录或要验证；都不是就换关键词 |
| 任务状态「疑似风控」「卡住了」 | 连续几批没数据 / 好几分钟没进展 | 过一会儿再点「继续」；排队的任务会先暂停自动开跑 |
| 视频「下载链接已过期」 | 平台给的下载地址失效了 | 重新抓一次同样的关键词或作者，再点「重试」 |
| 顶部「查看拦截日志」 | 排查问题用的 | 平时不用管；遇到解决不了的问题，可以截图连同问题描述一起反馈 |

## 六、删除和恢复

- 在程序里删视频、删文件 / 文件夹，文件会放进 **回收站**，删错了可以从回收站还原。
- 删掉的视频会留一个「已删除」记号：以后追更、重搜碰到它都会跳过，不会再下回来。
  后悔了就在任务里点「已删除(N)」→「恢复下载」。
- 删任务、删作者会先弹窗说明会删掉什么，已下载的文件留在磁盘上。

## 七、整理和处理

- **设置 → 下载后分文件夹整理**：可以单独勾选「按关键词 / 按品类 / 按作者 / 按横竖屏 / 按时长」，勾几层就建几层文件夹；
  一项都不勾，视频直接放在下载目录里。按关键词时，同一个关键词抓的放一起，抓达人主页的放「达人主页」。
- 勾了「按品类分文件夹」时：作者已有品类就沿用，没有就放进「未分类」。想让 AI 判断品类，在「设置 → AI 配置」里填好 API Key。
- 下载的都是平台上的原视频，不会重新编码。需要统一分辨率时，去 **视频处理** 页对整个文件夹处理一遍：
  默认结果放进这个文件夹下的「已处理」文件夹，原片不动；也可以选「替换原文件」（原片另存一份 `.original.mp4` 备份）。
- **素材库** 页用封面浏览下好的视频，能按平台、关键词、标记筛选，按点赞、收藏排序；每条可以打星标 / 待用 / 已用、写备注。
  勾几条点「打包交付」：复制到你选的文件夹，附一份「来源清单.csv」（标题、作者、链接、点赞……），
  可以顺便统一分辨率、交付后标成「已用」。原视频不动。
- **文件管理** 页按文件夹浏览下载目录，可以定位、导出表格、删除。

## 八、自动化（设置 → 自动化）

- **缩到托盘**：勾上后点窗口的 × 只是藏起来，程序在后台继续抓、继续下载。右下角托盘图标点一下就能打开；要真正退出，右键托盘图标点「退出」。
- **系统通知**：任务抓完、平台没登录、要过验证码、被限流时，右下角弹通知（窗口在前台时不弹）。点通知打开程序。
- **每天定时追更**：到点给爬过主页的作者各建一个「只抓新视频」任务，排队一个个爬，全部结束后弹一条汇总。
  错过了点（比如下午才开电脑），开程序后补跑一次。程序要开着（可以缩在托盘）才会跑。
  追更时平台网页窗口会自己弹出来，抓完会收回去。也可以点「现在追更一次」，或者右键托盘图标点「现在追更一次」。

## 九、注意事项

**别开多个程序窗口。** 同一个数据目录只能开一个程序，第二次打开会直接切到已经开着的那个窗口。

**别抓太猛。** 一次几千条、或者很多人共用一个账号大量抓，会明显提高风控（验证码、限流甚至封号）的概率：

- 单次目标数量控制在几百以内
- 用自己的账号
- 设置里的滚动参数用默认值就好：滚动间隔 3500、每页最大等待(秒) 8、停滞检测(秒) 25

## 十、数据存在哪

- **视频文件**：设置里指定的下载目录
- **任务记录、登录状态**：`%APPDATA%\video-scraper`（在文件管理器地址栏粘贴这个路径就能打开）

换电脑时，**先关掉程序**，再把 `%APPDATA%\video-scraper` 整个文件夹拷过去，任务记录和登录状态都能带走。

## 十一、本机接口（给其它程序用）

**设置 →「和百家号发布助手打通」** 里的本机接口开着时，同一台电脑上的其它程序（比如作者自用的百家号发布助手）
可以通过 `http://127.0.0.1:47321` 让本程序去抓某个作者的主页。
只接受本机程序的请求，网页发不进来。用不到的话可以在设置里关掉。
