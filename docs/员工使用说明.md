# 视频爬取工具 —— 使用说明

## 一、拿到的东西

一个文件：**`视频爬取工具-绿色版.exe`**（约 124MB）。

免安装。放哪都行（建议放到一个固定文件夹，别放桌面/临时目录），双击就能用。
不用装 Node、不用装 ffmpeg、不用配任何环境。

## 二、第一次打开

Windows 会弹蓝色窗口拦一下，写着「Windows 已保护你的电脑」。

**这是正常的** —— 因为这个程序没有买代码签名证书，不是有病毒。处理方式：

1. 点窗口里的 **「更多信息」**
2. 再点右下角出现的 **「仍要运行」**

之后每次打开就不再拦了。

第一次启动会慢一些（要把内容解压到临时目录），等十几秒是正常的。

## 三、开始用之前，先做两件事

### 1. 设下载目录

进 **设置** 页，把「下载目录」改成你自己的路径，比如 `D:\抖音视频`。

**注意选一个空间大的盘。** 视频很占地方，爬几百条就是几十 GB。

### 2. 扫码登录抖音

点开抖音浏览器窗口，会显示抖音页面。按正常方式**扫码登录你自己的抖音账号**。

登录状态会记住，以后不用重复扫。

## 四、怎么爬

1. 填关键词（或作者、话题）
2. 填目标数量 —— **建议先填 20 试一次**，跑通了再加大
3. 开始

爬取过程中程序会自己滚动页面加载更多，**不用你手动操作**。

爬完会自动下载，并按 `品类\作者\一分钟内|一分钟外\` 归档到你设的下载目录里。

## 四点五、把已有的作者名单导进来

如果你手上已经有一份作者名单（Excel 表、或者别人发你的一串链接），不用一个个建任务。

进 **作者收藏** 页，点 **「导入作者」**，两种方式任选：

**方式一：直接粘贴。** 一行一个，格式是「作者名 + 空格 + 完整主页链接」：

```
张三 https://www.douyin.com/user/MS4wLjABAAAA...
李四 https://www.douyin.com/user/MS4wLjABAAAB...
```

逗号、Tab 分隔也行，链接放前面放后面都行。

**方式二：选 CSV 文件。** 点「选择 CSV 文件」。你的表里只要有「作者名」和「主页链接」两列就行，
**其他列（粉丝数、备注等等）程序会自动忽略**，列的顺序也无所谓。

> ⚠️ **Excel 文件（.xlsx）不能直接选**。请先在 Excel 里「文件 → 另存为」，格式选 **CSV**，
> 再选那个 .csv 文件。（直接选 .xlsx 程序会提示你这一点，不会出乱码。）

导入后每一行的结果都会列出来，失败的会写明原因（比如「暂不支持短链接」——
手机分享出来的 `v.douyin.com/xxx` 那种短链认不了，得用完整主页链接）。

### 导进来的作者会显示「待校验」

这是正常的。程序不知道你填的名字和链接是不是同一个人，所以**第一次点「爬主页」时会自动核实**：

- 名字和链接对得上 → 正常开爬
- **对不上 → 不会爬，并在链接下面标红写明**「主页作者是「王五」，与你填的「张三」对不上」

看到标红就说明那一行的名字或链接填错了，改完重新导入即可。

### 复制作者数据到你自己的表格

框选想要的行（按住左键拖动），然后用工具条上的三个按钮：

- **复制所选** —— 作者名和链接一起复制，粘进 Excel 会自动分成两列
- **只复制作者** —— 只要名字
- **只复制链接** —— 只要链接

也可以点 **「导出 CSV」** 把整张作者表导出成文件。

## 五、会遇到的情况

| 现象 | 说明 | 怎么办 |
|---|---|---|
| 任务自动暂停，提示「已重搜 3 次仍爬不满」 | 可能没有更多结果，也可能是没登录 / 有验证 | 先看任务行的暂停原因和平台状态灯，打开对应平台窗口确认；登录或完成验证后点「继续」，再考虑换关键词或调小数量 |
| 弹出验证码 / 机器人验证 | 抖音风控 | 程序会自动暂停。你在抖音窗口里**手动完成验证**，然后点「继续」 |
| 任务显示「已暂停」，错误是 stalled | 页面卡住不出新内容 | 点「继续」重试；反复如此就换关键词 |
| 顶部「查看拦截日志」 | 排查用的，能看到程序在干什么 | 出问题时先看这里，截图给技术 |

## 六、注意事项

**别开多个程序窗口。** 同一台机器只能跑一个，多开会互相抢数据库，导致数据错乱。

**别爬太猛。** 目标数量一次填几千、或者好几个人同时用同一个账号大量爬，会明显提高抖音风控（验证码、限流甚至封号）的概率。建议：

- 单次目标数量控制在几百以内
- 每个人用自己的账号
- 别把设置里的「滚动速度」调快 —— 默认的「慢」就是为了降低风控

**设置里这三项别乱调**（默认值是测出来的，调错会导致爬不动）：

- 滚动间隔：3500
- 每页等待(秒)：8
- 停滞检测(秒)：25

> 如果你把「停滞检测」调得太小，程序会自动兜到安全值并在日志里说明 —— 但还是别调。

## 七、数据存在哪

- **视频文件**：你在设置里指定的下载目录
- **任务记录、登录状态**：`%APPDATA%\video-scraper`（在文件管理器地址栏粘贴这个路径就能打开）

换电脑的话，把 `%APPDATA%\video-scraper` 整个文件夹拷过去，任务记录和登录状态都能带走。

## 八、和百家号发布助手一起用

本程序只管把作者的视频下下来,处理和发布交给「百家号发布助手」:

- 发布助手 **设置 → 发布** 里填本程序的下载目录(留空它会自己读),它会把「品类\作者\」里新下的视频按作者名拉进各达人的暂存。
  **作者文件夹名要和发布助手达人表里的 达人名 或 站外昵称 一样**,对不上的它会在日志里列出来。
- **设置 → 和百家号发布助手打通** 开着本机接口(默认端口 47321)时,发布助手或它的助手可以直接让本程序去抓某几个作者的主页。
- **「统一输出分辨率」建议关掉**:开着时每条视频下载完都要用 CPU 重新编码,下载会慢好几倍;发布助手处理时反正会再编码。

## 九、暂时用不了的功能

**AI 自动判断品类**（听语音 + 看画面识别作者属于哪个品类）目前**没有开启**，因为需要配置 API Key。
现在的归档规则是：作者已有品类 → 沿用；没有 → 归到「未分类」。

需要开启的话找技术在设置页填 Key。
