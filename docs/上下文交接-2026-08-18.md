```js
colors: { brand: colors.teal, success: colors.emerald, warning: colors.amber, danger: colors.red }
fontFamily: { sans: ['"Segoe UI"','"Microsoft YaHei UI"','"Microsoft YaHei"','"PingFang SC"','sans-serif'] }
```
- **brand-600 = `#0D9488`**
- **字体栈刻意不写 `system-ui`**：中文 Windows 上它直接解析成雅黑 UI，会吃掉后面 Segoe UI 的机会，而雅黑西文/数字字形更差
- **色相约束**：brand 只用于「可点的主操作」（主按钮/激活导航/焦点环/选中底色/框选遮罩）。**状态色不许用 brand** —— teal-600 与 emerald-600 色相差仅约 12°，红绿色觉异常者（男性约 8%）无法区分。`downloading`/`running`/进度条一律用 **sky**

### `ROW_BAR`（TaskList 行首色条，P4 教训的样板）
```ts
const ROW_BAR: Record<string, string> = {
  failed: 'border-danger-400', downloading: 'border-sky-400',
  pending: 'border-sky-400', done: 'border-success-400'
}
const rowBar = (status: string): string => `border-l-2 ${ROW_BAR[status] ?? 'border-transparent'}`
```
**必须完整字面量 Record，绝不可 `` `border-${x}-400` ``** —— 拼接类名会被 Tailwind purge。
**无状态也必须渲染 `border-l-2`**（用 `border-transparent`），否则状态变化时整列横移 2px。

## 7. 已确认的重要事实

### 红线（交接文档 §5 与历轮血泪）
1. **`updateBrowserDisplay`**（`src/main/index.ts:37-40`）的 `taskRunning || forceBrowserFull` 优先级逻辑 —— **一个字不动**。本轮主进程零改动
2. **`abortScroll` 信号链路**、秒级心跳、自救循环三出口结构、长操作超时、爬满即停、重启恢复任务入队
3. `npm run dev`/`start` 的 `cross-env NODE_OPTIONS=--experimental-sqlite` 不许手改

### 布局硬约束（**改 UI 前必读**）
1. `main.flex-1 overflow-auto` 是**全站唯一纵向滚动容器**，所有面板自身无高度约束
2. 任务页必须保持 `hidden` 常驻挂载，**TaskList 不能被 remount**（`dom-contract.test.tsx` 有断言）
3. 导航项必须是原生 `<button>` 且可访问名严格等于 `任务`/`使用说明`（`aria-label` 已把名字钉死）
4. 表格容器 `data-testid`（`video-table`/`authors-table`/`files-category-table`/`files-author-table`/`select-all`）、行 `data-id`/`data-selected`、行内按钮的原生 `<button>` —— **四样不能动**
5. `SelectContainer` 结构契约：直接子元素必须是**唯一 `<table>`**，中间不得插 wrapper
6. **任何 `main` 的祖先都不得有 `transform`/`filter`/`backdrop-filter`** —— 会让框选遮罩画歪（选中结果仍对，纯视觉错，jsdom 100% 测不出）且让 `fixed` toast 换包含块。**当前侧边栏用 `fixed` 脱离文档流，所以它不是 main 的祖先，这个风险被结构性消灭**
7. `check:css` 读 `out/renderer/assets`，**必须先 build**

### 性能/阻塞事实
- **`scanFilesTree`（`src/main/fileManager.ts`）是同步 `readdirSync`+`statSync` 跑在主进程上** —— 扫描期间所有 IPC、窗口事件、下载器回调全部排队。**绝不能自动触发**
- `downloader` 每个视频至少 emit 3 次状态（pending/downloading/done）。500 个视频 ≈ 1500 次事件
- `downloader` 的 `queue`/`active` 是 private 且无 IPC —— 概览页用 `Σ videos.pending` / `Σ videos.downloading` **近似**，文案刻意写「待下载 N · 下载中 M」而不是「队列深度」

### 抖音窗口（已核实，与 DOM 布局零耦合）
- 无 parent 的独立顶层 BrowserWindow，位置只在**首次 show 时算一次**（`browser.ts` 的 `positioned` 标志），全仓库无 resize 订阅
- 真正的耦合是「谁在什么时候调 `showBrowser`/`hideBrowser`」的状态机 —— P1 已收敛为 effect

### 其它已确认
- `node:sqlite` 在 Electron 35.7.5 **不带 `--experimental-sqlite` 也可用**（真主进程实测）
- `videos.status` 入库默认值是 **`pending`**（不是 collected）
- `insertVideos` 签名是 **`(db, items, taskId, platform)`**（参数顺序易错）
- `border-brand-600` 全仓库唯一出处 = SideNav 激活左竖条（原来是顶部 tab 下划线）
- `video:status` 事件载荷**没有标题**，只有 `{type, id, status, error?, localPath?}`

## 8. 已尝试但失败 / 被否决的方案

| 方案 | 结果 | 原因 |
|---|---|---|
| **给单元格加 `select-text` 让文本可选中** | **被用户否决，已整体撤回** | 作者名和链接两列占行宽大部分，从它们上面起手就拖不动框选 = 用框选换复制。改为「复制所选/只复制作者/只复制链接」三个按钮 |
| **概览页做「实时活动流」（监听 video:status）** | 设计阶段否决 | 事件载荷没有标题，渲染出来是「#412 下载完成」用户不认识；并发 3 时每秒好几条人眼读不了；不提供决策信息。改用 `stats:recent` 查库 |
| **布局用「新增 `div.flex.flex-1.min-h-0` 包住 aside+main」** | 设计阶段否决 | 它创造了一个既是 main 祖先、又是布局动画天然落点的容器。改用 fixed 侧边栏，风险被结构性消灭 |
| **侧边栏折叠动画** | 明确不做 | 桌面窗口 ≥1280px 折叠省不出有意义空间，却是遮罩错位/toast 漂移唯一现实的触发场景。有测试断言 SideNav 的 innerHTML 不含 `translate-`/`scale-`/`transition-all` |
| **引 lucide-react 等图标库** | 否决 | 离线绿色版交付；用量仅 22 个；图标库的 IconButton 封装常包 span/div，会破坏 `closest('button, a, input')` 框选守卫 |
| **暗色模式** | 用户否决 | 工作量翻倍，员工白天办公室用，浅色更合适 |
| **把 stats 提到 App 层往下分发** | 设计阶段否决 | App 每收一个事件就 setState 会重渲染整棵树（含 hidden 的任务页子树）。改用聚合 IPC |
| **趋势图/时间序列** | 本轮不做，记 deferred | 需要新查询 + 手写 SVG 图表，纯装饰且会显著撑大代码量 |
| **给 useCoalescedRefresh 加 cleanup 调 hideBrowser** | 明确不加 | `main.tsx` 有 StrictMode，加 cleanup 会让切到浏览器页变成 show→hide→show |

### 工程教训（会反复踩）
- **bash heredoc 与 Python 字符串会各自吃掉一层转义**：`'\n'` 会变成真换行 → 「Unterminated string literal」；`\t` 会变成制表符本体（不可见字符）。**稳妥做法：用 `chr(92)` 拼反斜杠，或改用不需要转义的等价写法（模板字符串 / 正斜杠路径）**。长文件用 Write 工具而不是 heredoc
- **JSDoc 注释里写 `ffmpeg*/bin/` 会让 `*/` 提前闭合块注释** → 语法错误。写成 `ffmpeg<版本>`
- **TS 模板字符串里 `\s` 会被吃成 `s`**（页面注入脚本），必须写 `\\s`
- **CSS 里类名是转义的**（`.py-0\.5`、`.bg-brand-200\/40`、`.text-\[10px\]`、`.focus\:ring-brand-500:focus`），用字面量 grep 检查会把存在的类误报成被 purge。`scripts/check-css.mjs` 已逐字符转义处理
- **子 agent 并行规则**：只准 `npx vitest run <指定文件>`，禁止全量 `npm test`/`typecheck`/`build`（仓库根 `.tsbuildinfo` 与测试固定临时目录会被并发写坏）。**长构建任务（`npm run dist`）绝不派子 agent**（第十五轮因看守超时卡死过）
