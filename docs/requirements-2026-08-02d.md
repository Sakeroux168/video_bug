## 1. 核心诉求（3 条）

### ① 抖音窗口显示回归修复

- **根因**：第三轮 T1 把程序化显示改成 `showInactive()`，但 Windows 上 `SW_SHOWNOACTIVATE` 对**从未显示过的窗口是空操作** → 抖音窗口永不出现（打开按钮无反应、抓取看不到页面）。
- **修法**：`setVisible` 加 `everShown` 标志——首次显示用 `win.show()` + `setImmediate(() => win.blur())`（显示但不抢焦点），之后再显示用 `showInactive()`。恢复全部显示路径：打开抖音窗口按钮 / 浏览器 tab / 抓取时 / 验证时。
- **验收**：点「打开抖音窗口」窗口出现；抓取时窗口显示且不抢焦点；验证时窗口出现；不回归第三轮焦点修复。

### ③ 选择语义终版（**取代**第三轮"替换+框内翻转"）

| 手势 | 语义 |
|---|---|
| 点行（无修饰键） | **排他**：只选该行、清空其它；点已选中的行 → 清空全部 |
| **ctrl+点** | **切换**该行选中（不清其它） |
| **shift+点** | **范围选中**：从锚点到当前行全部选中；锚点 = 最近一次普通点击/shift 点击的行（ctrl 点击与框选**不改**锚点） |
| 框选（拖动） | **纯替换**：框住的全部选中（含已选中的保持），框外全部取消 |
| 点空白 | 清空 |

- **验收矩阵**（用户指定，逐条通过）：
  1. 1/2/3 已选中 → 框选 2/3/4 → 结果只留 2/3/4（1 自动取消）
  2. 再框选 5/6/7 → 结果只留 5/6/7（2/3/4 取消）
  3. 点 1 → 只留 1
  4. shift+点 4 → 选中 1~4
  5. ctrl+点 5 → 新增 5（当前 1~5）
  6. ctrl+点已选中的（如 2）→ 去掉 2，其它保持
- 两表格（视频表格 + 作者表格）一致；批量按钮计数（下载选中 N 等）与跨页完整 selected 语义保持；didDrag 防误伤保持。

### ④ 筛选续爬修复

- **触发（项目负责人推荐，用户采纳）**：
  - 主规则：**15 秒无新视频入库** → 触发（scheduler 记录 lastFetchedAt，每轮检查；与 fetched 增长联动）
  - 辅规则：滚到底后 **DOM 找底部文案** → 找到立即触发。**抖音底部实际文字 = 「暂时没有更多了」**（用户实测确认），检测正则 `/没有更多|到底|暂时没有/i` 覆盖其变体（"没有更多了"/"暂时没有更多"等），并兼容其它可能的表述
  - 两者先到先触发；只应用一次；仍仅 keyword 任务
  - **不做截图匹配**（需图像库、受缩放/暗黑模式影响，DOM 文本更简单，匹配不到由 15s 兜底）
- **交互修复**：筛选面板是 **hover 弹出**（鼠标移开即消失）→ 注入脚本改 `mouseover/mouseenter/mousemove` 触发筛选按钮（保留 click 兼容），面板出现后点配置项，连续操作不离开面板；面板未出现/选项缺失 → 记失败。
- **失败兜底**：触发失败 → `task:notice` 提示「筛选续爬未生效（页面结构可能已变）」，按原逻辑停，不卡死。
