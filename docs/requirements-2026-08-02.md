## 2. 核心诉求（4 条，均已澄清确认）

### A. 爬取控制修复（3 个主进程 bug）

| bug | 根因 | 修复 |
|---|---|---|
| A1 暂停后要等几秒才能点继续 | `task:pause` 置 `aborted=true` 但 `run()` 的 while 循环还在长 sleep 里，旧循环未退出前点继续被 `if (this.running) return` 静默丢弃 | 暂停**即时打断**当前等待（可中断 sleep）；`run()` 快速退出后继续立即可点，恢复不丢 |
| A2 抓取超过指定条数 | `handleRaw` 把整批解析结果全插入，最后一批常超 20+ 条 | 插入时**硬截断**到目标数（fetched 到达 target 即停，不多插一条） |
| A3 下滑太快、不等当页加载完 | 滚动循环固定节奏，不感知页面是否加载出新内容 | 每轮滚动后**等待页面高度增长/新条目出现**（带超时上限）才继续下一轮 |

### B. 归档修复 + 时长细分目录

- 上一轮红灯根因：自动归档绑死「AI 下载后整理」勾选，用户没勾 → 下载完完全没归档（手动挑选下载也一样）。
- **确认**：总是自动归档，不依赖任何勾选。AI 只负责定品类：配了 AI 用 AI 品类 → 失败/未配用作者已有品类 → 都没有归「未分类」。
- 新增时长二级目录：`品类\作者\一分钟内\视频`（≤60s）与 `品类\作者\一分钟外\视频`（>60s），自动/手动下载统一适用。

### C. 页面重组（任务 / 作者 两页）

- 顶部 tab：**任务**（筛选表单 + 任务表格，每行可展开看该任务视频 + 下载操作）/ **作者收藏**（作者表格）/ **内置浏览器** / **设置**。
- 任务列表、作者收藏都是**表格形式**，缓解「管理面板」一页三块过于拥挤的问题。

### D. 选择交互重做（表格通用）

- **点行任意位置** = 切换该行选中（勾选框/链接/按钮照常）。
- **点击表格空白处** = 清空选择。
- **框选**（拖动）：**替换式**——框住的选中、框外的一律取消勾选；已选中的再框一遍 = 取消。
