# 小红书试用说明

这是开发工作区的新功能，尚未作为员工正式版本发布。

1. 在“内置浏览器”选择小红书并登录。
2. 回到抓取页，平台选“小红书”，可以使用关键词、话题或作者主页，第一次建议目标填 3 条。
3. 选“自动下载”会在取得视频地址后下载；选“手动挑选”只先收集信息。
4. 关键词和话题任务会先尝试在网页筛选面板选择“视频”；近7天同时选择“一周内”。近30天、自定义日期以及全部时长条件，会在详情阶段按真实字段精确过滤。
5. 作者任务从主页中带播放图标的卡片收集视频，图文卡片不会进入详情阶段；页面滚动时会继续收集后续作品。
6. 遇到验证弹窗会暂停，请手动完成验证后点“继续”。需要停止时使用任务的暂停或取消按钮。

有些候选可能已删除、详情打不开或不符合筛选条件，所以实际数量仍可能少于目标。启用时间或时长筛选时，程序会多收集一批候选再逐条核对，以减少过早停止。

下载与视频处理沿用现有设置；是否统一分辨率取决于设置，不会因为选择小红书而强制开启。
