# 小红书筛选与作者主页调研

## 本机页面证据

本轮通过可操作的网页浏览器检查，未把旧文档当成当前页面事实。

- 普通 `/search_result` 页存在 `div#video.channel`（文字“视频”），点击后地址出现 `type=51`。这是一次实际点击的观察，尚不能证明重新导航后对所有账号都生效。
- 从当前账号首页的搜索输入框搜索后，进入 `/search_result_ai?keyword=<二次编码>&source=unknown`，与项目原有搜索地址一致。这里顶部是“笔记 / 用户”，不是普通搜索页的“全部 / 图文 / 视频”。
- AI 搜索页实测筛选按钮为 `div.filter.ai-chat-filter`，文字“筛选”，哈希位于 Vue 的 `data-v-*` 属性；并非所有可用定位标识都是哈希。
- 点击筛选没有展开浮层；用户手动悬停可展开，社区实现也确认它依赖 hover。接入代码因此使用 Chromium CDP 派发真实鼠标移动，而不是调用元素 `click()`。
- 从搜索卡片打开公开作者主页成功；随后去掉作者链接的查询参数，干净的 `/user/profile/<uid>` 在当前登录态下仍能加载作者资料、“笔记 / 收藏”和作品列表。
- 作者卡片实测使用 `.note-item[data-note-id]`；视频卡片带 `.play-icon`。详情链接形态为 `/user/profile/<uid>/<note_id>?xsec_token=<token>&xsec_source=pc_user`，图文与视频卡片都可有令牌，因此必须结合播放图标筛视频。本记录不保存任何真实令牌。
- 作者卡片会随页面滚动继续渲染；程序每轮滚动后重新扫描，按 note ID 去重。

## 接入方向

1. AI 搜索页固定尝试“笔记类型→视频”；近7天额外映射为“一周内”。筛选前的首屏候选会清空，筛选失败则恢复原候选并由解析器兜底筛视频。
2. 发布时间先使用网站可精确映射的范围减少候选，再用详情时间戳过滤；项目“近30天”和自定义日期不会错误映射成“一周内”或“半年内”。
3. 时长继续在详情阶段过滤；启用时间或时长条件时，候选最多扩到目标的三倍（总上限 1000），减少少数不合格候选导致的过早结束。
4. 作者从登录态可打开的干净主页开始，详情上下文从当前页面卡片读取；`xsec_token` 和带令牌 URL 只在任务内存里使用，不落库、不进日志。
5. 沿用页面自行请求、程序旁听的方式；不新增签名生成器，不自动点赞、关注或发消息。

上述方案已在代码中接入。普通搜索页的 `type=51` 仍未生搬到 AI 搜索网址；AI 页使用实际筛选面板，面板不可用时保守回退。
