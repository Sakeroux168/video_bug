# 项目交接文档（视频爬取工具）

> 生成日期：2026-08-05（对应 git HEAD：`9a21103`，含 10 轮验收修复全部历史）

## 1. 这是什么

**抖音视频批量爬取桌面程序**（Electron + React + TS）。内嵌抖音浏览器（独立窗口）扫码登录 → 按关键词/作者/话题抓取 → 无水印下载 → 按 `品类\作者\一分钟内|外\` 归档 → 可选 AI（本地 sherpa 中文转写 + 多模态视觉）判定作者品类。历经 10 轮验收修复，当前 280 个测试全绿、typecheck/build 通过。

## 4. 核心机制速览

- **抓取**：浏览器窗口滚动（页面级中止信号：暂停 1 秒内停）→ 注入 fetch/XHR 挂钩把接口 JSON 发给主进程 → `scheduler.handleRaw` 按任务类型过滤接口 → 解析（`aweme_info` 包装解包）→ 去重(seen) → **硬截断到目标数**（不多插一条）→ 入库。
- **筛选续爬**：搜索到底（可见的「暂时没有更多了」**带可见性+视口校验**，防隐藏 DOM 提前命中）或 15 秒无新视频 → **每轮检查**（不依赖停滞分支）→ CDP 真实鼠标悬停筛选按钮（哈希类名会变，按钮/面板/选项**多候选：类名→文字/语义属性**）→ 单脚本内 el.click 点选项（面板丢失自动重悬停重试）。
- **下载**：全局队列并发 3；`playwm→play` 无水印变体回退；ffprobe 视频轨校验（黑屏防护）；暂停/取消/单条暂停用 AbortController 掐断（abortReasons 快照区分全局暂停/单条暂停/取消）；重启只重排 pending，paused/collected 不动。
- **归档**：下载完成自动触发（**不依赖 AI 勾选**）→ 按作者分类（AI 听+看 → 作者已有品类 → 未分类）→ 移入 `下载目录\品类\作者\一分钟内(≤60s)|一分钟外\`；幂等（只移平铺层文件）。
- **诊断**：顶部「查看拦截日志」面板显示所有接口/筛选 `[筛选]` 前缀全链路日志；「手动测试筛选」（头部，带日志）与筛选模块内「测试筛选」（静默版）两个按钮。

## 5. 已知坑与约定（新接手必读）

1. **哈希类名会变**：抖音 CSS 哈希类（`bR4uhU1W`、`nU717OFZ` 等）每次发版都可能变——所有页面元素查找必须走**多候选**（类名 → 文字/语义属性）+ 可见性校验；真机失效时先看 `[筛选]` 日志（会打点候选命中情况）。
2. **`node:sqlite` 需要实验 flag**：`npm run dev` 已带；vitest 用 `tests/helpers/node-sqlite.cjs` shim。
3. **ffmpeg 路径**：`F:/123/ffmpeg*/bin/` 扫描 + PATH 兜底；新机器要装。
4. **用户反馈流程**：用户把实测问题写进 `F:\123\爬取标题遇到的问题.txt`，Claude 读文件 → requirements skill 梳理 → 确认 → SDD 派单实施。用户习惯每轮后丢反馈文件。
5. **登录态**：抖音登录存在 userData 分区（`persist:douyin`），搬迁 userData 后免重扫码。
6. **别手改**：`updateBrowserDisplay` 的窗口显隐、`abortScroll` 信号链路、`filterInFlight` 互斥锁——都是多轮血泪修出来的。

- 质量岗位：任务审查官（每任务 spec+质量）、复审官（修复轮）、总审查官（opus 整支终审）。

- 账本与 deferred 清单在 `.superpowers/sdd/`（git 忽略）——**交接需手动拷贝**。

## 9. 交接步骤（老机 → 新机）

**老机（这台）**：
1. `cd F:\123\爬取视频 && git status` 确认干净（当前已干净）。
2. 打包代码：`git bundle create 爬取视频.bundle --all`（推荐，含全部历史）；或 zip 整个目录（**排除 node_modules/ out/**，到新机重装）。
3. 拷运行数据（可选但推荐，省重配）：`%APPDATA%\video-scraper` 整个文件夹（含登录态/设置/数据库/语音模型）。
4. 拷 ffmpeg：`F:/123/ffmpeg-8.0.1-essentials_build`（或新机装）。
5. 拷反馈文件 `F:\123\爬取标题遇到的问题.txt`（保持同名路径最省事）。
6. 拷账本（可选）：项目内 `.superpowers/sdd/` 整个目录。

**新机**：
1. 装 Node 22+（确认 `node -v`）。
2. 把项目放到**同名路径** `F:\123\爬取视频`（重要：Claude Code 项目记忆按路径挂载；路径不同则记忆不加载，需重建）。
   - git bundle 方式：`git clone 爬取视频.bundle 爬取视频` 或 `git bundle unbundle` 后 checkout master。
3. `npm install`（sherpa-onnx-node 是 N-API 预编译，win32-x64 直接可用）。
4. 放回 userData（第 3 步拷的 `video-scraper` 目录放到新机 `%APPDATA%\`）→ 免重扫码/重下模型；没拷就：设置页重配下载目录/AI Key → 设置页「下载模型」重下 ~240MB。
5. ffmpeg：放到 `F:/123/ffmpeg*/bin/` 或加 PATH。
6. `npm run dev` 冒烟：窗口弹出、登录态在、能建任务。
7. `npx vitest run` + `npm run typecheck` + `npm run build` 全绿确认环境 OK。
